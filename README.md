## 🛠 使用说明
1. 使用 Keil MDK 打开各个文件夹内 `.uvproj` 工程文件；
2. 根据硬件原理图完成单片机接线；
3. 编译下载至STC89C52RC开发板即可运行。
4. 实验按照编号顺序学习，由基础外设逐步进阶。
